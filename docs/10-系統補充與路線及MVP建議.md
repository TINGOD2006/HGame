# 系統補充與路線及 MVP 建議

> 日期：2026-10-22。依使用者逐項補充整理。已定規則以總覽 D32–D37 為準。
> B 的 Demo 基礎範圍、具體 [設計規格](superpowers/specs/2026-10-22-system-demo-design.md)與[實作計畫](superpowers/plans/2026-10-22-system-demo-implementation.md)均已確認，目前實作中；正式完整 MVP 與永久規則另定。此文其他建議僅在被該規格明確採用的範圍內作 Demo 設定。

## 1. 本次已確認的補充

- 讀檔後不會立即重新觸發魔化；讀檔次數須多，且其他條件滿足。回想模式不作計算。
- 每章安排一段特殊記憶；女主在指定位置／事件失敗後讀檔，觸發該章記憶。每章一段不代表必須收齊所有章才能進魔化。
- 魔化線的 H 技能更強，成人向表現更進一步，且有更特殊的技能。
- 重裝有特殊攻擊手段，攻擊力弱於劍士。舞者以暈眩所有敵人獲勝。
- 不遠征時可在城鎮購物、工作，或透過成人性工作取得金錢與 H EXP；各活動成本待定。
- 回想／畫廊重播不影響主線或記憶與讀檔等計數。所有重要路線分歧有選項與提示。

## 2. 路線歸屬：推薦一般結局作成功通關的保底

### 推薦原則

推薦在分歧場景列出目前符合條件的走向，由提示與選項決定是否進入特殊路線。尚未鎖線時，混用系統仍能繼續培養；特殊條件未達成而成功通關者，歸一般結局。

一般保底只適用成功通關，不把期限失敗或 Game Over 改成一般結局。中間善惡值的一般走向，也不提前封死尚未到來的特殊分歧。

### 邊界情況的推薦表（未定案）

| 狀態 | 推薦歸屬與處理 |
|---|---|
| 未鎖線、善惡中間、成功通關 | 一般結局；保留兩套系統的使用自由 |
| 高善惡、普通成長與探索足夠、符合純潔資格 | 在分歧場景開放純潔候選 |
| 高善惡，但已失去純潔資格或探索不足 | 未達其他特殊路線時歸一般，不自動改成色魔 |
| 高善惡、H 成長足夠 | 開放色魔候選；仍檢查其正式條件 |
| 普通與 H 混用，未達任何專精要求 | 繼續培養；最終成功通關時以一般保底 |
| 混用，但已同時達到多個候選條件 | 在分歧場景提供合資格選項；避免以少量技能使用次數暗中替玩家選線 |
| 低善惡、普通系統與失敗條件達標 | 開放黑化候選 |
| 低善惡、H 系統與失敗條件達標，但尚未感知玩家 | 暫不開放魔化；未鎖線者仍可後續累積，成功通關且未達特殊條件則一般 |
| 殘留記憶或讀檔次數多，但其餘魔化條件不足 | 不直接魔化；不因單一計數達標改線 |
| 已鎖特殊路線，後來出現其他候選條件 | 保持原路線；感知事件與分歧規則須避免繞過既有鎖線 |
| 讀回鎖線前的存檔，跨讀檔記憶仍在 | 不在載入瞬間重新鎖線；在後續正式分歧重新依條件與選項結算 |
| 期限失敗、尚未感知玩家或其他救援條件不足 | 不走一般保底，也不提供略過條件的魔化入口；失敗處理方式待定 |

主用系統的推薦做法是以實際養成與有意義的戰鬥成果提供候選資格，再讓玩家在分歧選擇。不要只靠施放技能的次數判斷，否則重複使用低成本技能容易扭曲路線。具體計分與門檻尚未選定。

## 3. 記憶與分歧的推薦銜接

推薦的候選判定順序為：指定失敗後讀檔觸發特殊記憶 → 多次讀檔及其他條件累積 → 女主感知玩家 → 於重要分歧顯示選項與提示 → 按選項及正式規則決定是否鎖線。玩家直到魔化結局才得知女主已察覺操作者。

以下細節仍需定案：

- 「讀檔次數」建議計正式遊玩後實際回退進度的載入；單純啟動遊戲繼續、設定畫面操作或畫廊重播不增加。此計數定義尚未批准。
- 建議每章特殊記憶有獨立識別，避免同一段被重複讀檔刷成多章記憶；是否保留重複觸發強度另定。
- 需指定失敗後讀回哪個範圍才算觸發，以及計數是否跨存檔槽、新遊戲或周目。
- 重要分歧提示可以說明重大性格／力量／難度變化及不可逆後果；結局前不顯示「女主知道玩家」等破壁答案。
- 若正式門檻要求多章記憶，第 1 章就無法以同一條件提供魔化救援；需等門檻定案後重新確認早期期限失敗處理，不另開無條件入口。

## 4. 職業與魔化技能的推薦

### 重裝

推薦以防禦後反擊、蓄力或破防建立特殊攻擊手段；單次直接攻擊力維持低於劍士，讓耐久與準備行動產生價值。這些機制尚未選定。物理技能消耗 HP，因此重裝的減傷、技能成本與恢復必須一起檢視，避免低 HP 下重複施技失去風險。

### 舞者

推薦「讓所有仍在場的敵人同時暈眩」作勝利條件，形成安排控制順序與持續時間的策略。若只需每名敵人曾經暈過一次，逐個標記就容易完成，群體控制的特色較弱。

Boss 建議有較高暈眩抗性或累積需求，保留達成勝利條件的途徑；永久免疫會使舞者無法靠其核心玩法通關。是否採用抗性累積、增援處理及是否允許 HP 歸零勝利仍待確認。舞者暈眩勝利對普通／H 階段的適用範圍也尚未決定，不能直接覆蓋既定敵方精力歸零規則。

### 魔化 H 技能

推薦挑少量技能做出可辨識的強化，例如多目標、連鎖結算、獨有狀態與被動，成人向演出維持結構層規劃。具體效果未定，不先寫入資料 schema。

魔化應能帶來明確的強度提升；後續敵人變化可以回應新技能的策略，避免只用全體敵人數值等比例上調抵銷獲得力量的感受。魔化力量的世界觀來源仍未補齊。

## 5. 城鎮活動的收益與時間

推薦一般工作偏穩定的金錢收入，成人性工作同時給金錢與 H EXP，但兩者的時間成本和收益須一起比較。若後者在相同成本下連金錢都全面勝出，一般工作容易失去用途。

建議先用每次工作佔一個行動時段作比較基準，再依遊玩節奏調整；購物是否耗時另定。報酬、H EXP 與章節成長上限尚未配置，避免靠重複城鎮活動略過迷宮資源與成長節奏。

性工作本身不自動改寫善惡或路線。是否改變純潔資格，由指定事件的實際狀態效果另行定義，並在選項提示後果；不能把全部 H EXP 來源視為同一類事件。畫廊重播不再次取得金錢、EXP 或狀態效果。

## 6. MVP 範圍分析（B 的 Demo 基礎範圍已確認）

### 三個切片選項

| 選項 | 內容 | 可驗證內容與代價 |
|---|---|---|
| A：單章基礎戰鬥展示 | 一章、普通與 H 戰鬥、基本城鎮活動 | 最快看到核心循環；無法充分比較不同章的特殊記憶累積 |
| B：一章可玩內容＋第二章記憶驗證段落（推薦） | 一章完整系統循環，另有第二章的一個指定失敗／讀檔記憶段落 | 同時驗證戰鬥、日程、城鎮、跨讀檔與跨章記憶；不必量產第二章完整內容 |
| C：四職業、兩風格與五條完整路線 | 完整玩法方向大量納入 | 製作與平衡成本最高，迭代時牽動最多；目前不建議作第一個切片 |

選項 B 的第二章用於驗證不同章記憶各自觸發，不代表魔化必須兩章記憶才能成立。每章 20 天的正式日程規則保留，切片以少量節點與占位內容呈現；不是製作四十天完整劇情。提早通關後的章節結算時點仍需先定。

### 推薦 B 的具體候選內容

- 普通職業先放劍士與舞者：前者提供 HP 戰鬥基準，後者驗證全體暈眩勝利。術士與重裝保留完整版本方向，不在此次推薦切片量產。
- 先用一種 H 風格與一個魔化專屬技能驗證兩階段結算與強度差異，不等於刪除第二種風格。
- 第一章保留三階段、六個存檔點與 20 天日程；第二章只做特殊記憶驗證段落。
- 用兩種一般敵人與一種 Boss 起步，確認三種勝利方式：敵方 HP 歸零、敵方精力歸零、舞者全體暈眩。
- 三類城鎮活動各有一個占位選項：購物、一般工作、成人性工作；先驗證成本與報酬，具體事件腳本與量產 CG 待後續。
- 五條路線先完成條件表與開發用結果判定；可玩切片優先呈現一般與魔化的分歧節點，不製作五條完整結局。正式魔化結局的破壁揭露不提前放進對外試玩版。
- 畫廊至少能重播一項占位內容，驗證它與正式遊玩的狀態完全隔離。

### 原建議驗收情境

以下保留原討論。Demo 已依後續批准規格完成對應切片驗證，結果見 [驗證摘要](../verification/summary.md)；完整版路線與期限救援仍待後續定案，不能由 Demo 推導全部通過。

1. 劍士能正常獲勝、進入 H 階段並結算；舞者能以全體暈眩獲勝，Boss 也有可達成的策略。
2. 每章指定失敗後讀檔會觸發對應特殊記憶；普通讀檔不立即魔化。
3. 畫廊重播不改金錢、EXP、善惡、事件旗標、記憶、讀檔或路線條件。
4. 正式分歧有選項與提示；讀回分歧前不在載入瞬間重新鎖線。
5. 未達魔化必要條件時不能透過期限救援繞過；成功通關的邊界狀態依已批准的路線表處理。
6. 城鎮工作與遠征在時間和資源上都有用途，不以單一活動全面取代探索。

原十週規劃使用舊系統，無法直接套用。先定下零 HP 續戰、H 結算公式、舞者判定、分線門檻、城鎮行動成本與新切片，再按實際工作量重估排程。

## 7. 最值得接著定案的事項

1. 路線表是否採一般結局作成功通關保底，候選資格如何讓玩家選擇。
2. 舞者是否必須同時暈眩全體，以及 Boss 與 H 階段規則。
3. 讀檔門檻、每章記憶的重複觸發與跨槽／跨周目邊界。
4. 普通與 H 戰鬥的零 HP 續戰、MP 支付與傷害轉換。
5. 城鎮活動時間與報酬，然後確認 MVP 切片與排程。
