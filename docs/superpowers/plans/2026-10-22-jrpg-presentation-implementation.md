## 3. T1：共同契約與狀態

地圖 schema 描述 ID、章節、尺寸、主題、地板／裝飾／阻擋格、出生點、互動點與節點 ID。互動點包含穩定 ID、座標、面向、顯示名稱及種類；具體圖塊索引交給資產 adapter，不讓玩法資料依賴未知下載順序。

新增純資料 WorldPresentationState：版本、地圖 ID、格子 X／Y、朝向、章節及對應節點錨點。掛在 RunState，透過 GameSession 專用展示更新入口寫入，不修改資源、路線、記憶或時間線計數。UI 不直接修改快照。

只有到達完整格子時更新可存位置。安全存檔時與 Run 一起保存；位置變動本身不扣時段、不建立回退節點、不每幀寫檔。載入後由 Unity 層核對位置是否屬於目前地圖、可通行且不超越進度；缺欄位、空 ID、過期錨點或無效座標皆回到合理出生點。

統一存檔安全判斷需結合 Core 資格與實際地圖位置；不能只沿用殘留 CurrentNodeId 或 Battle.IsTerminal。迷宮手動／自動存檔只在對應存檔錨點互動範圍或戰後返回格成立，離開後即不再符合該錨點資格；城鎮維持原本允許的安全範圍。安全閘門須涵蓋所有實際寫槽入口，不只將按鈕停用。舊檔缺展示位置時，先解析合理安全出生點再判斷。

保留既有存檔 envelope／交易的相容讀取與完成標記檢查；若新增欄位，不能假設 JsonUtility 的 null inline class 會保持 null。Meta／Profile 語意不變。

## 4. T2–T4：地圖與互動

取得已確認候選的官方 CC0 包，下載至 work 暫存，讀包內授權後才選檔匯入。地圖圖塊採 Point 過濾、不產生 mipmap、相容透明貼圖設定；不更改既有 Noto 字型與授權。新資產只用於占位地圖、小人、物件及敵人；成年角色範圍維持既有規則。

以 SpriteRenderer／可替換格子資料建立世界；沒有必要為小範圍原型新增第三方地圖框架。渲染依 Y 深度排序；角色影子、遮擋與碰撞層分開。靜態障礙不可通行，鏡頭以正交投影跟隨、夾在地圖邊界，小地圖維持置中。

探索控制器只輸出移動／互動意圖。WASD／方向鍵單軸移動，E／Enter 只在按下當次互動；長按不重複買物或開事件。按 Esc 開選單，任何選單、確認、過場、戰鬥或結果頁開啟時均阻止移動和場景互動。

城鎮用工作／商店／職業／旅店／入口互動點開啟精簡功能視窗；消耗、成功與拒絕原因均取正式 GameSession。深夜換旅店室內，出口鎖定，次日回城。關閉介面與取消購物不扣時間。

迷宮節點對應既有 c1_n01–12 與第二章資料。障礙／門不能讓玩家繞過前置節點或日期；阻擋原因由 Core 的可用行動／NodeReason 決定。每趟上限或零 HP 時提供明確恢復／返城入口，不讓玩家被困在地圖。接敵有確認與完成標記，已清理敵人不在返回幀立即重觸發。

## 5. T5：橫向戰鬥展示

主 agent 建立獨立 BattlePresentation／BattleView，沿用 Session 作唯一判定來源。UI 顯示背景、敵人左側、女主右側、HP／MP／H／精力／暈眩與目前目標；多敵採不重疊站位。

選定行動後先鎖輸入，一次提交正式命令，依提交前後快照顯示位移、閃光及數字；動畫結束才解鎖或進結果頁。被拒絕的命令顯示理由，不播放虛假的成功效果。此版只做簡易表現，不新增戰鬥規則。

Core 若已回到 Dungeon 或 Town，展示層仍可暫時顯示本次戰鬥快照與結果，但不再次計算戰果；確認結果後刷新世界。切主選單、讀檔與換地圖需取消舊動畫／輸入回呼，避免舊結果覆寫新旅程。

## 6. T6：位置與存讀檔

測試點包含城鎮、存檔點、戰後安全位置、舊版存檔、無效位置與最終敗北。繼續同旅程應恢復安全位置；讀回分歧前仍還原路線及感知，保留合資格記憶，不立即鎖線。

手動存檔仍只在原規則允許的位置；迷宮走到其他格子不等於新增存檔點。遊戲轉為深夜、返城、章末或失敗時，以規則位置為優先，防止存檔顯示角色留在不合法戶外區域。

## 7. T7：計畫中的驗證範圍

以下須在本計畫確認、對應實作完成後才執行，不將現有 43 項結果當作新版本通過證據：

- 重新執行原 EditMode 測試，確認新展示狀態未改變既有戰鬥、記憶、路線與交易恢復。
- 僅新增針對性測試：邊界／阻擋／單軸移動、互動只觸發一次、選單／動畫輸入鎖、地圖與節點引用、無效／舊版位置 fallback、保存／恢復位置不增加回退。
- 位置專用案例：行走／轉向後時間線 head、時段與 Meta 不變；載入相同 head 但位置不同的安全存檔，仍須恢復該檔位置，且不增加回退。
- 生命週期案例：動畫／結果頁未結束時載入或返回主選單另開旅程，等待超過原動畫時間後，新旅程／位置／資源／獎勵／路線不被舊回呼改寫，控制鎖正常解除。
- Windows Player 在 1280×720、960×540 走查新遊戲、行走、碰撞、互動、開關選單、接敵、攻擊／技能／目標、戰鬥結果返回、HP 0 返城、存讀檔、畫廊與分歧入口。
- 部分移動與互動使用 Input System 合成鍵盤事件，戰鬥使用指標事件及正式命令。報告需區分真正輸入事件與直接命令；不宣稱人工完整操作。
- 獨立關閉與重開 Player，驗證 Continue 旅程、位置、回退計數與畫廊保留。
- 實際截圖核對地圖、人物／敵人站位、互動提示、選單、目標、戰鬥狀態與小視窗裁切。依具體失敗修正；不為追求測試數量持續擴張。

Editor 測試與建置序列化；新增自動驗證只寫獨立 Verification 子目錄。不得修改玩家正式資料以方便展示。
