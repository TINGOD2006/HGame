# Unity 系統 Demo 設計規格

日期：2026-10-22。狀態：已依使用者確認的 Demo 範圍完成設計草案，等待書面審閱。尚未建立產品程式、Unity 專案或可玩建置。

本規格以總覽 D1–D39 為設計來源。使用者已確認製作 Unity Demo、允許暫用免費素材，並選擇玩法、程式、QA 三個本次聊天用協作角色。以下數值與細則是第一版 Demo 的明確驗證設定，須經本規格審閱後才實作；不自動改成完整版的永久決策。

## 1. 目標與交付

交付 Windows x64 可執行 Demo、Unity 專案原始碼、啟動說明、第三方素材來源／授權清單，以及實際驗證紀錄。

玩家可完成城鎮準備、早上遠征、節點探索、普通或 H 戰鬥、晚上返城、深夜休息的循環。可用劍士擊敗敵人、以舞者令全體暈眩獲勝，或轉入 H 階段耗盡敵方精力。指定點失敗後的真實讀檔能觸發特殊記憶，達到條件後在有提示的分歧選擇走向。畫廊重播不改變正式遊玩狀態。

第一章保留 20 天、三階段、六個存檔點；第二章只提供另一段特殊記憶的驗證內容。暫以狀態文字、節點圖、已接受的成年女主概念圖及免費圖示呈現事件；不量產正式劇情、成人 CG 或五條完整結局。Demo 結尾為試玩完成頁，正式魔化結局的玩家身分揭露保留在完整版。

## 2. 技術與協作範圍

- Demo 環境選用已在本機確認可執行的 Unity 6000.3.7f1；原完整版技術決策仍記錄為 6000.3.10f1，此處是此次原型環境選擇。
- URP 2D、uGUI、Input System、Windows x64。套件採相容的官方 UPM 來源；本機有模板與 Windows 模組，不以此宣稱能完全離線解析套件。
- 遊戲規則置於無 UnityEngine 依賴的 HGame.Core；Unity 控制器、UI、檔案操作置於 HGame.Unity；建置與資料檢查置於 HGame.Editor。首版採一個 Demo 場景，以面板切換主選單、城鎮、迷宮、戰鬥與畫廊。
- Demo 的事件以資料定義輸出狀態及選項；保留 DialogueService 介面。Ink 的正式劇本與逐字播放整合留待劇情階段，不在本版撰寫完整劇本。
- 玩法角色負責暫定規則審閱，程式角色負責工程實作，QA 角色負責驗收，主 agent 整合與最終檢查。工具任務名稱為 game_designer、game_programmer、game_qa；都是此次聊天的子 agent，不宣稱跨聊天持續存在。
- 外部模型執行器未被選定，不預設派給其他模型。

規劃的產品檔案範圍：Assets/_Project 下的 Core、Runtime、UI、Data、Scenes、Art、Editor 與 Tests；Packages、ProjectSettings、第三方授權目錄、建置／啟動腳本及說明。Library、Temp、Logs、UserSettings 與建置產物依忽略規則處理。現有 output/ 及其他既有文件內容不作為自動清理對象。

## 3. 遊玩畫面與操作

主要流程：主選單 → 城鎮 → 迷宮節點 → 戰鬥 → 結果／返城。存讀檔、物品、回想與重要分歧以面板顯示。

- 主選單提供新遊戲、繼續、存檔選擇、回想、離開，顯示成年角色與內容類型說明。
- 常駐資源列顯示章／日／時段、HP／MP、金錢、普通／H 成長、目前職業。舞者戰鬥另顯示敵方暈眩累積與剩餘回合；H 階段顯示雙方 H、敵方精力與剩餘使用額度。
- 主選單與畫廊不顯示內部玩家感知旗標。記憶提示只呈現異樣、片段與不連續感，分歧提示說明力量、難度與路線後果。
- 主要畫面具有背包、恢復品與返回操作；戰鬥可防禦、使用物品或撤退，避免剩餘 MP 無法施技時卡住。戰鬥中使用物品占一次女主行動；撤退結算為本次最終敗北並返回城鎮。
- 以 1280×720 視窗起步，版面可隨視窗縮放；繁中字型打包進產物。鍵鼠操作都有清楚的按鈕狀態與原因提示，沒有資源時不可執行的動作需顯示原因。
- 開發診斷資訊與正式面板隔離；不得靠預設開啟的診斷捷徑取代正常可達成的遊玩流程。

## 4. 章節、時段與探索

- 每章第 1、3、6 天開放第一、二、三階段；只有早上能遠征，消耗早上與中午，正常結束或撤退時為晚上。首章第 1–2 天用引導提示教學，仍計入日程。
- 每階段四個線性占位節點，其中兩個為存檔點；全章十二節點、六個存檔點。單趟最多新增四節點，即一階段的永久進度；既有存檔點可作後續進入位置。
- 第一階段依序是指定記憶戰鬥／存檔點／補給取捨／存檔點；第二階段是多敵戰鬥／存檔點／第二次補給取捨／存檔點；第三階段是多敵戰鬥／存檔點／Boss／存檔點。兩個補給選項保證善惡可從 50 降至 30；地圖已完成節點不重複發獎。
- 第一章第一階段有一個指定記憶戰鬥，第二章驗證段也有自己的指定記憶戰鬥。兩者使用不同章與記憶識別。其內容是狀態提示，不撰寫正式劇情。
- 存檔點只存檔，不免費恢復。普通失敗依事件於晚上返回城鎮，HP／MP 保留失敗實際值，並計一次當局最終敗北；指定直接 Game Over 事件顯示讀檔面板。
- 第一章 Boss 提早被擊敗後仍可使用剩餘天數；第 20 天深夜結算後才進第二章。提供正常的等待／休息行動度過時段，不用開發跳日代替流程。
- 日間等待只消耗一個時段，不免費恢復；深夜休息的恢復與換日依下表結算。
- Boss 通關後另有「休整至章末」選項，明確提示會用完剩餘行動、不取得額外金錢或 EXP；確認後推進至第 20 天結束並結算。玩家仍可選擇逐日使用剩餘時間；此選項不在第 20 天以前開放下章內容。
- 第二章驗證段完成一次指定記憶流程或選擇完成試玩時顯示 Demo 完成頁，保留繼續驗證存檔的入口。
- 第 20 天尚未完成攻略時顯示期限失敗與載入選項。期限魔化救援的時間、次數及鎖線覆蓋尚未定案，本版不實作該救援；不提供繞過魔化必要條件的入口。
- 深夜只能室內休息或讀寫存檔，城鎮外出與遠征入口皆不可用。

## 6. 戰鬥狀態與結算

### 普通階段

女主選動作 → 驗證資源 → 支付成本 → 逐個效果 → 勝負檢查 → 尚未結束才依序處理敵人。普通階段 MP 為 0 不敗北，只限制支付 MP 的動作。

普通階段在全部敵人 HP 歸零時獲勝。舞者另有勝利條件：至少一名敵人仍在場，且所有在場生存敵人同時暈眩。暈眩累積達門檻時暈眩兩個敵方回合，期間跳過該敵行動，跳過後才減剩餘回合。女主動作結束後先檢查全體暈眩，再進敵方回合。Boss 能被累積暈眩，本版沒有永久免疫或增援。此規則只用於普通階段，H 階段依全體敵人精力歸零判勝。

女主被敵人擊倒時先依戰鬥事件規則分流。直接 Game Over 事件進讀檔；允許 H 續戰且仍有 MP／使用額度時顯示被動入場選項，與主動入場原因分開記錄。被動入場本身不等於最終敗北；一場戰鬥只在最終敗北時增加當局敗北數一次。

被動 H 選項可以拒絕；拒絕或資源不足時，依普通最終敗北於晚上返城並計敗北一次。第一章指定記憶戰鬥使用這種可返城的失敗型態，保證當局敗北數能在不讀檔的情況下正常累積。

### 普通轉 H

每個仍存活敵人只折算一次既有 HP 傷害；已被普通攻擊擊敗的敵人不加入 H 階段。

~~~text
傷害比例 = (最大 HP − 現有 HP) / 最大 HP
等值 H 進度 = floor(傷害比例 × 初始精力 × 100)
現有精力 = 初始精力 − floor(等值 H 進度 / 100)
H 槽 = 等值 H 進度 % 100
~~~

例：初始精力 3、損失 50% HP，轉換成精力 2、H 50。精力與 H 槽合計只表達同一份傷害進度，不各自完整扣一次。轉換後該階段不再用原 HP 判定敵人敗北。

### H 階段

所有主動 H 技能必須付費後仍保留 1 MP，否則禁用；最後 MP 的歧義以此 Demo 規則消除。敵方 H 達 100，精力減 1、H 減 100；可按溢出逐次處理。女主 H 達 100，MP 減 3、H 減 100；MP 歸零立即敗北。每個效果後檢查終局，一旦勝負成立就停止後續效果、敵方動作與重複獎勵。

H 階段可使用 MP 恢復品、免費等待讓敵方推進回合，或放棄並按最終敗北返城。H 等待不減少敵方 H 增量。MP 只剩 1 且沒有道具時，仍能等待或放棄，不能讓全數按鈕禁用而卡住。

H 勝利保留實際 HP／MP，不回滿、不補到 1。若 HP 為 0，顯示戰後恢復／安全返城面板；可用物品、於當前安全存檔點存檔或返城，恢復正 HP 前禁止新戰鬥與深入探索。不重新觸發擊倒，也不再次增加敗北。沒有恢復品時仍能返城，等待付出時段成本的恢復。

## 7. 存檔、記憶與讀檔計數

### 資料邊界

- 當局存檔 RunState：旅程識別、時間線節點識別、章／日／時段、HP／MP、成長、背包、金錢、善惡、純潔資格、地圖進度、當局最終敗北數、已經歷事件識別、玩家感知與路線鎖定。讀檔會回退這些資料。
- 同旅程保留資料 MetaState：有效回退次數、時間線父子關係與最後遊玩位置、待處理／已處理失敗憑證、各章特殊記憶、被抹去的痛苦／親密事件核心。同旅程跨存檔槽共享；新遊戲建立新旅程，隔離前次記憶。這是此次 Demo 選擇，完整版跨周目規則尚未裁決。
- ProfileState：設定、音量與已解鎖回想，跨新遊戲保留；播放畫廊不新增女主記憶或主線事件。這項範圍同樣是 Demo 工作假設。
- 主線資料與畫廊展示資料不同實例；畫廊沒有寫入 RunState／MetaState、發獎、產生失敗憑證或增加計數的權限。

### 有效回退

每次正式遊玩產生唯一時間線節點與父節點。載入同旅程的祖先或旁支，且捨棄了目前分支至少一項實際新經歷或行動，才增加一次有效回退；日期或資源差異不單獨作為依據。相同節點、目前節點的後代、單純啟動後繼續、立即連按同一載入、畫廊與設定畫面都不增加。切換另一旅程不混計。

指定點最終失敗產生一次性憑證，記錄旅程、章、事件與時間線節點。當載入捨棄的路徑包含該指定失敗，才接收該章特殊記憶；同一憑證只處理一次，同章重複失敗不被當成多章特殊記憶。第二章使用另一個記憶識別。普通成功後讀檔、非指定點失敗後讀檔、指定點失敗但未讀檔，均不產生該章特殊記憶。失敗後才建立的存檔仍包含該次失敗，載入它不會觸發抹去該次失敗的記憶。

殘留記憶記得事件核心，但時間順序與來由模糊。所有路線都適用此規則；畫廊回想只讀播放。當局最終敗北數仍會隨讀檔回退，不能暗中把它改成永久失敗計數。

使用一個手動槽與一個自動槽起步。僅在安全狀態存檔：城鎮時段交界、存檔點、戰鬥／事件結束；事件與分歧結算中途不存檔。失敗憑證先持久化，讀檔結算使用一次性交易識別，重啟恢復時不重複加次數。檔案放 Application.persistentDataPath 下的 HGameDemo，包含版本與備份，先寫暫存檔再替換；初次寫檔與替換既有槽分開處理。損壞或不相容時顯示訊息並保留可讀備份，不靜默清空記憶。

## 8. 路線與分歧的 Demo 判定

### 一般條件

完整五線先有開發用候選判定，對外 Demo 主要遊玩一般／魔化分歧。其他正式路線內容與結局不量產。

- 高善惡為至少 70，低善惡為至多 30；中間且未鎖線者維持一般候選。
- 普通／H 等級至少 2，且有該方式的實際戰鬥勝利，才開放對應專精候選；混用時可有多個候選，分歧只提供合資格選項。
- 純潔候選另需當前時間線符合純潔資格與第一章探索至少 80%；色魔需高善惡及 H 專精；黑化需低善惡、普通專精與當局最終敗北至少 2。
- 成功通關且未鎖任何特殊路線時，以一般候選保底。期限失敗不套用此保底。

### 魔化門檻與因果

Demo 暫定門檻：有效回退至少 3、至少 1 章特殊記憶、當局最終敗北至少 2、善惡至多 30、H 等級至少 2且有 H 勝利、尚未鎖其他特殊路線。

門檻齊全時只開放隱晦的重大轉變分歧。選項提示力量提升、未來敵人／難度變化及鎖線後果；主 UI 不寫出玩家感知旗標或真相。選擇維持現狀則保留模糊記憶，不完成玩家感知事件或鎖線。

城鎮室內提供可重訪的「記憶異樣」入口；至少取得一章特殊記憶後可查看隱晦提示。門檻齊全才出現重大轉變選項；取消後仍能再次查看，Boss 提早通關後亦不消失。單純重開或取消未改變狀態的面板不新增有效時間線行動。

選擇接受轉變時，於同一次不可中途存檔的事件結算中依序執行：重驗其他門檻 → 女主內部感知玩家存在 → 重驗必要感知旗標 → 鎖定魔化與難度。感知先於鎖線，卻不會在未選魔化的其他路線自行成立。後續以隱晦狀態呈現崩潰與行為轉變，Demo 不說破玩家身分。

讀檔函式只恢復當局資料、接收合資格記憶與計數；不執行路線鎖定。即使 MetaState 的條件還在，讀回分歧前仍需再次遊玩至正式分歧並選擇。原先已鎖其他特殊路線者不開放魔化覆蓋。

魔化後解鎖一個全體 H 技能，後續戰鬥使用對應配置；本版只驗證效果與配置切換，不製作完整新敵人陣營或正式魔化結局。

正常驗證路徑：先累積兩次普通最終敗北並返城 → 保存敗北數為 2 的基準 → 在指定記憶點失敗後讀回基準 → 再做兩次帶新行動的有效回退 → 兩次補給負向選擇、H 等級 2 且至少一次 H 勝利 → 回城重訪分歧並確認。讀回保有兩次敗北的基準，不會讓當局敗北門檻變成不可達。上述流程須在真實可玩版中驗證，開發工具不能代替。

## 10. 驗證與完成條件
