# 俯視探索與橫向戰鬥 Demo 設計規格

日期：2026-10-22。狀態：**使用者已確認本書面規格**。採 B：傳統日式 RPG、俯視地圖上下左右行走、戰鬥採橫向站位。以下配置與展示細節限 Demo 0.2.0，不代表完整版地圖或玩法已定案。

## 1. 目的與範圍

將現有 0.1.0 的按鈕面板式探索改為能實際行走的日式 RPG 展示。讓玩家體驗「在城鎮準備 → 走到入口遠征 → 地圖接敵 → 橫向回合制戰鬥 → 返回原位置 → 返城休息」。正式地圖與新玩法由使用者後續補充，本版以可替換測試場景承載現有規則。

交付 Unity 原始碼與新的 Windows x64 可玩包，舊版 ZIP 保留。版本暫定 0.2.0。沿用本機 Unity 6000.3.7f1、URP 2D、uGUI、Input System；沿用本次聊天已選的玩法、程式、QA 角色及主 agent 整合。

## 3. 探索與操作

- 16:9 橫向視窗；主要面積顯示地圖，角色保持可見。鏡頭跟隨並限制於地圖邊界。
- WASD／方向鍵四向行走；同時按兩方向時選單一軸，不加入斜向加速。使用平滑的格子間移動及方向／走路狀態展示。
- E／Enter 與面前一格的 NPC、門、存檔點或補給互動；畫面顯示互動名稱及按鍵提示。
- Esc 開關選單，選單含物品、職業、存讀檔、畫廊、說明及返回主選單。戰鬥仍可用滑鼠選指令與目標。
- 對話框、選單、場景切換或戰鬥期間禁止地圖移動；按鍵需釋放後才能再次觸發一次性互動。
- 牆壁、樹、水及建築阻擋通行；角色不能出界或穿過互動物件。

## 4. 測試地圖

### 城鎮

一張小型可行走城鎮，安排旅店、商店、工作窗口、職業窗口及迷宮入口。靠近並互動才開啟相應視窗。購買／工作等既有命令成功時才扣時間；走路與瀏覽不扣時段。

工作窗口沿用一般工作與抽象成人工作選項，成人題材僅保留既有狀態／資源結算。角色與參與者均成年，沒有新增成人腳本或 CG。

深夜進入簡單旅店室內測試區，出口提示當晚不能外出；可休息、使用物品及存讀檔。休息後到次日早上，再回城鎮入口位置。

### 迷宮

一張測試迷宮，保留現有第一章 12 節點與第二章驗證段資料的關聯。以走廊、房間、入口與三段區域展示位置，並設可見的敵人、補給與存檔點。三階段的日期與每趟新增進度上限仍由既有 Core 判斷。

- 敵人先採固定可見接敵：走到互動範圍、確認接敵後進入戰鬥；不新增巡邏 AI 或隨機遇敵機率。
- 未開放區域顯示阻擋與原因；完成前一節點後才可進入下一段。不能單靠地圖走位略過 Core 條件。
- 勝利後敵人標示已完成，不因剛返回地圖就自動再次開戰；是否重戰由明確互動選項決定，既有重訪不重領 EXP 規則保留。
- 第一、二章讀取對應示範佈局與互動 ID；第二章仍只為記憶驗證用途。

上述位置、大小與路徑只供試玩，不代表正式地圖已由使用者批准。

## 5. 橫向回合制戰鬥

- 戰鬥背景占畫面上方主要區域，成年女主站右側，敵人站左側；下方為狀態、指令與戰鬥訊息。
- 可點敵人選擇目標，明確顯示目標標記。單敵／多敵／Boss 均保持可見，介面不遮住角色。
- 普通攻擊、技能與受擊先以短位移、閃光、傷害／回復數字及勝敗過場展示；暈眩與階段切換有可辨認狀態。
- 沿用普通 HP、H／精力、舞者同時暈眩、HP／MP 支付底線、被擊倒續戰、魔化技能與獎勵判斷。此版本不增加即時戰鬥、跳躍或新職業。
- 一次指令結算與動畫完成前不能重複操作；避免同一次點擊重複發獎或扣資源。
- 戰鬥結束有簡短結果提示，再返回對應探索位置；最終失敗依既有規則回城。HP 0 的 H 勝利後可恢復或安全返城，不能走入下一探索節點。

## 6. 素材與介面

先用一致的免費像素地圖與占位行走角色，搭配現有繁中 UI／字型及已接受的成年女主概念圖。行走圖與戰鬥圖不作最終角色定稿；不把整張角色設定表直接當作地圖小人。

候選地圖資產為 Kenney Tiny Town／Tiny Dungeon，官方頁皆列 CC0；實際取得後仍核對包內授權，僅匯入使用子集並更新素材紀錄。原圖附件的忽略指示持續適用。

- https://kenney.nl/assets/tiny-town
- https://kenney.nl/assets/tiny-dungeon

探索時僅保留必要的章節、日期／時段、HP／MP、金錢與互動提示。大型角色面板與行動按鈕移入選單／互動視窗。保留重要分歧確認與結果提示，魔化結局前不明示玩家身分。

## 7. 工程與資料邊界

- 保留 HGame.Core 的規則與正常命令入口；移動、鏡頭、地圖顯示及動畫放在 Unity 展示層。
- 地圖使用可替換的格子資料：尺寸、地板／裝飾／阻擋層、出生點、互動 ID、現有節點 ID。資料與材質不硬寫在核心規則內。
- 新增地圖控制器、移動／碰撞控制器、互動控制器及戰鬥展示控制器；共用一個 Session／SaveRepository，避免另建與真實主線不同步的展示狀態。
- 展示位置包含地圖 ID、格子與朝向，安全存檔時一併保存；新版本讀到舊存檔或無效位置時，依當局城鎮／迷宮節點選安全出生點。不得改動 Meta 記憶與回退語意。
- 地圖事件透過正式命令更新後再刷新；讀檔必須重建地圖狀態、關閉原互動／戰鬥動畫，避免載入後保留舊畫面。
- 0.1.0 的核心測試與驗證紀錄保留，不能把舊報告稱為 0.2.0 新版驗證結果。

## 8. 建議完成條件

1. 在城鎮實際四向行走、碰撞、開關選單，並與工作／商店／旅店互動。
2. 早上經入口進迷宮；日期、路徑、每趟進度與深夜外出限制符合既有規則。
3. 由地圖接敵，完成劍士、舞者與 H 戰鬥，展示指令／目標／受擊／結果並返回正確位置。
4. 存讀檔與關閉重開後，角色位置可恢復或安全回退；記憶、計數、路線、獎勵不被展示動畫改動。
5. 既有畫廊與重大分歧可由新版選單／互動入口到達。
6. 建立新版 Windows 包與操作說明，明列實際執行的建置、測試／走查及限制；驗證執行範圍另於實作計畫列出，取得使用者授權後才執行。
