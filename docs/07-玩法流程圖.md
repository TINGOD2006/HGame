# 玩法流程圖

> 2026-10-21。只描述系統，不包含劇情腳本。
> 實線表達目前流程；標「待定／建議」的節點不是已定參數。正式條件以 [玩法決策紀錄](06-玩法決策紀錄-2026-10-21.md) 為準。

## 1. 章節與期限

~~~mermaid
flowchart TD
    A["開始新遊戲：成年女性主角"] --> B["首章第 1–2 天教學，計入期限"]
    B --> C["本章每日流程"]
    C --> D{"本章迷宮攻略完成？"}
    D -->|是| E["標記本章成功，保留剩餘天數"]
    E --> F["可作本章活動，不開放下章內容"]
    F --> G["章節正式結算，具體切換時點待定"]
    G --> H{"最後一章？"}
    H -->|否| I["下章第 1 天：繼承成長與路線"]
    I --> C
    H -->|是| J["依有效路線條件進入五種結局之一"]
    D -->|否| K{"第 20 天結束？"}
    K -->|否| L["進入次日"]
    L --> C
    K -->|是| M["期限失敗 CG 與 Game Over 分流"]
~~~

## 2. 每日四時段

遠征佔早上與中午是目前流程提案；活動細項與成本待配置。深夜不能外出，不可誤寫成只禁止出城。

~~~mermaid
flowchart TD
    A["早上：檢查狀態與期限"] --> B{"今天出發？"}
    B -->|是| C["遠征：早上與中午"]
    C --> D["晚上返城與結算"]
    C -->|直接 Game Over| X["回檔流程"]
    B -->|否| E["早上活動"]
    E --> F["中午活動"]
    F --> D
    D --> G["晚上活動"]
    G --> H["深夜：室內活動或休息"]
    H --> I["日結算與存檔"]
    I --> J["依章節成功及期限狀態前進"]
~~~

## 3. 迷宮開放與推進

每迷宮總共六個 save point；「三階段各兩處」是工作理解，待確認使用者的階段／節點用語。存檔點與其他手動／自動存檔不一定相同。

~~~mermaid
flowchart TD
    A["早上決定遠征"] --> B["讀取目前日期與永久進度"]
    B --> C{"可進入的階段"}
    C --> D["第 1 天起：第一階段"]
    C --> E["第 3 天起：第二階段"]
    C --> F["第 6 天起：第三階段與 Boss"]
    D --> G["選擇可達節點"]
    E --> G
    F --> G
    G --> H{"節點類型"}
    H -->|戰鬥| I["普通或 H 戰鬥"]
    H -->|物品或事件| J["按設定處理獎勵與狀態"]
    H -->|存檔點| K["保存進度，恢復功能待定"]
    I --> L["更新本次推進量"]
    J --> L
    K --> L
    L --> M{"達單次最多三分之一，或選擇撤退？"}
    M -->|否| G
    M -->|是| N["晚上返城"]
~~~

## 4. 普通戰鬥與深度模式入場

物理技能最低保留 1 HP，法術使用 MP。主動入場與被擊倒入場分開；指定直接 Game Over 事件不擅自改為救援。事件分支重疊時的優先序待定。

~~~mermaid
flowchart TD
    A["普通戰鬥階段：女主單人"] --> B{"女主行動"}
    B -->|物理| C["支付 HP，最低保留 1"]
    B -->|法術| D["支付 MP"]
    B -->|已解鎖輕度 H 技能| E["支付 MP，效果規則待定"]
    B -->|已解鎖主動深度技能| F["主動入場：不視為被敵人擊倒"]
    C --> G["結算技能與勝負"]
    D --> G
    E --> G
    G -->|敵方 HP 歸零| H["普通勝利"]
    G -->|仍在戰鬥| I["按順序處理敵方行動"]
    I --> J{"女主 HP 歸零？"}
    J -->|否| A
    J -->|是| K["被擊倒：檢查事件與入場資格"]
    K -->|直接 Game Over| L["回檔"]
    K -->|指定事件| M["依設定更新處女狀態或解鎖機制"]
    M --> N{"啟用 H 戰鬥？"}
    N -->|否| O["按事件結果處理"]
    N -->|是| P["被動深度入場"]
    K -->|已解鎖且允許續戰| P
    F --> Q["保留敵方既有傷害的百分比"]
    P --> Q
    Q --> R["轉換至 H 槽與精力，公式待定"]
    R --> S["進入 H 階段"]
~~~

## 5. H 階段逐次結算

圖中的行動結果按先後依序處理，不設同時敗北。付款、效果與最終檢查的詳細順序仍需配置。

~~~mermaid
flowchart TD
    A["H 階段：確認使用次數與資源"] --> B["當前行動者執行技能或被動"]
    B --> C["逐個結算效果與必要檢查"]
    C --> D{"本次效果作用哪方？"}
    D -->|女主| E["更新女主 H 與 MP"]
    E --> F{"H 達 100%？"}
    F -->|是| G["扣 MP，H 重置方式待定"]
    F -->|否| H{"MP 耗盡？"}
    G --> H
    H -->|是| I["女主最終敗北"]
    H -->|否| J["繼續當前流程或下一行動"]

    D -->|敵方| K["更新敵方 H 與精力"]
    K --> L{"H 達 100%？"}
    L -->|是| M["精力減少 1，H 重置方式待定"]
    L -->|否| N{"精力歸零？"}
    M --> N
    N -->|是| O["H 勝利：保留女主 HP 與 MP"]
    N -->|否| J
    J --> B
    O --> P["計入 H 等級限制的使用次數"]
    P --> Q["按續戰資格處理探索，零 HP 情況待定"]
~~~

H 使用次數的扣除時點也尚未定案；圖中勝利後記帳僅示意有此紀錄，不表示失敗或入場不消耗次數。

## 6. 路線判定

以下展示條件方向，不設定數值。純潔資格與 CG 解鎖分開管理。主用系統、高低善惡與其他條件尚需正式條件表。

~~~mermaid
flowchart TD
    A["動作或事件結算"] --> B{"已鎖定特殊路線？"}
    B -->|是| C["保持路線與難度，讀檔才能回退"]
    B -->|否| D{"已到分線判定時點？"}
    D -->|否| E["維持未鎖線"]
    D -->|是| F{"善惡區間"}
    F -->|中間| G["一般結局候選，不提前解除未來分線機會"]
    F -->|高| H{"主用系統"}
    H -->|普通| I{"深入探索且符合純潔資格？"}
    I -->|是| J["純潔候選"]
    I -->|否| K["條件不足的保底方式待定"]
    H -->|色色| L{"達到對應養成與條件？"}
    L -->|是| M["色魔候選"]
    L -->|否| K

    F -->|低| N{"失敗等條件已達標？"}
    N -->|否| K
    N -->|是| O{"主用系統"}
    O -->|普通| P["黑化候選"]
    O -->|色色| Q["魔化候選"]

    J --> R["完整條件成立後鎖定路線與難度"]
    M --> R
    P --> R
    Q --> R
    R --> C
~~~

「候選」不是提前播放結局；玩家仍須完成後續章節。中間值適用於未鎖線者，在最終結算時歸一般結局。

## 7. 期限失敗、回檔與魔化救援

此圖將已定的回檔與救援分開，沒有假定所有直接 Game Over 都能覆蓋既有路線鎖定。

~~~mermaid
flowchart TD

    C["第 20 天結束仍未攻略"] --> D["期限失敗 CG"]
    D --> E["保留 CG 回想解鎖"]
    E --> F{"可用處理"}
    F -->|讀取可用存檔| G["恢復存檔的遊戲狀態"]
    G --> H["重新安排與攻略"]
    F -->|申請魔化救援| I["檢查救援資格與路線鎖定"]
    I --> J{"允許？規則待定"}
    J -->|否| B
    J -->|是| K["轉入魔化救援，進度與時間處理待定"]
    K --> L["本章取得較容易的攻略條件"]
    L --> M{"攻略結果"}
    M -->|成功| N["本章完成"]
    N --> O["後續敵人與難度採魔化路線變化"]
    O --> P["走向獨立魔化結局"]
    M -->|失敗| Q["再次失敗處理與救援次數待定"]
~~~
