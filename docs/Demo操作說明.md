# HGame Unity 系統 Demo 操作說明

版本：0.1.0。使用 Unity 6000.3.7f1 製作，Windows x64。

## 啟動

完整解壓縮可玩包，執行 HGameDemo.exe。保留同層 HGameDemo_Data、UnityPlayer.dll、MonoBleedingEdge 與其他隨附檔案，不能只複製 exe。原始建置位於專案 Builds/HGameDemo。

主選單可開始新旅程或繼續最近安全進度。新的旅程有獨立的記憶；手動存檔仍可載入原旅程，已解鎖畫廊保留。

## 基本操作

- 使用滑鼠點選按鈕，行動區可用滑鼠滾輪或右側捲動條查看更多選項。
- 在城鎮切換劍士／舞者；每天早上決定遠征。工作或完成購物會占用一個時段，只有瀏覽或取消購物不扣時間。
- 一般工作取得金錢；成人工作只有抽象的報酬及 H EXP 結算。所有角色及參與者均成年，Demo 沒有成人 CG 或正式劇情演出。
- 遠征於晚上返回，深夜只能室內休息與記錄。深夜休息恢復 HP／MP 並換日。
- 第一章三階段分別於第 1、3、6 天開放；一趟最多新增一個階段進度。六個存檔點能記錄，不免費恢復。
- 補給節點有一次性的資源取捨；選項會說明金錢與善惡變化。

## 戰鬥

- 點選敵人作目標，再選行動。劍士用普通攻擊與耗 HP 技能削減敵方 HP；物理技能支付後須保留至少 1 HP。
- 舞者的群舞累積敵方暈眩；所有仍在場敵人同時暈眩即普通勝利。Boss 也能靠累積暈眩攻略。
- 主動深度技能使用 MP 與一次當日 H 額度。敵方已受的 HP 傷害會以同一份百分比進度折算至精力與 H 槽。
- H 階段敵方 H 每到 100 扣 1 精力；全體精力歸零獲勝。女主 H 達標扣 MP，MP 歸零敗北。
- H 技能支付後須保留 1 MP。資源不足時可使用恢復品、等待或放棄，不會沒有可用操作。
- 被敵人擊倒後可選擇是否續戰；H 勝利不免費補血。HP 為 0 時先使用恢復品或安全返城，不能繼續深入。

## 存檔、記憶與畫廊

城鎮、存檔點與已結束戰鬥的安全位置可手動存檔；系統另有自動槽。讀檔恢復該存檔的當局資源、進度及路線，並依正式規則保留合資格的模糊記憶。正常啟動繼續不算一次回退，載入也不會當場替玩家鎖定新路線。

每章有一個特殊記憶位置；該處最終失敗後讀回失敗前存檔才會觸發該章記憶。不同章分開計算，重複載入同一狀態不會冒出另一章記憶。

重要分歧有選項與後果提示。可在城鎮重訪記憶異樣入口，條件達成時查看重大轉變；取消後仍能再次查看。完整開發驗證路徑見專案 verification/ui-walkthrough.md。

畫廊只重播已解鎖片段，無主線報酬、記憶、讀檔或路線副作用。

## 試玩範圍

第一章保留 20 天日程。提早打贏 Boss 可繼續使用剩餘日子，或確認休整至章末。第二章只提供另一個記憶驗證段落，可選完成系統試玩或繼續驗證。

本版是系統原型：兩個普通職業、一種 H 風格、一個魔化技能與節點式畫面；使用暫定數值、免費 UI 與原先接受的概念造型。正式角色、劇情、CG、其餘職業與完整五線結局留在完整版範圍；期限魔化救援尚未納入此 Demo。

## 資料與原始碼

遊玩資料儲存在 Windows 使用者的 AppData/LocalLow/TINGOD/HGame System Demo/HGameDemo，屬正常存檔位置。自動驗證使用其下獨立 Verification 子目錄，與正式旅程分開。

原始碼可用 Unity 6000.3.7f1 開啟目前儲存庫；Editor 選單 HGame/Prepare Demo 與 HGame/Build Windows Demo 分別設定場景及建置。素材原授權在產物 ThirdParty；完整來源紀錄在 docs/第三方素材授權紀錄.md。
