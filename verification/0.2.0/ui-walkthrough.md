# 0.2.0 操作與驗證路徑

## 正常遊玩

1. 新旅程位於溪畔小鎮。WASD／方向鍵行走，面向北側商店／旅店、南側工作／職業窗口或入口路標按 E。
2. 選單用 Esc 開關。購物、工作成功才占時段；純行走、瀏覽與取消不扣時間。
3. 早上在遠征入口確認出發，於迷宮面向敵人按 E，確認接敵。
4. 戰鬥左側為敵人，右側為女主。先選目標，再選指令；行動動畫後可繼續。結果頁選繼續旅程返回地圖。
5. 依房間與走廊順序完成節點，閘門需前一節點完成。三階段仍在第 1／3／6 天開放，單趟最多新增四節點。
6. 開選單→物品與資源，可使用物品或安全返城；HP 0 時另有畫面直接返城按鈕。存檔只在城鎮／存檔點互動範圍／戰後安全格；離開安全格後停用。
7. 深夜留在旅店，面向床位按 E，再選休息。次日恢復資源並回城。
8. 重要記憶入口仍由城鎮／旅店路標進入；畫廊位於選單。規則門檻與完整示範序列見 JrpgSmokeRunner 及舊版玩法規格，沒有新增正式劇情。

## 實際自動走查方式

Windows Player 內的 JrpgSmokeRunner 只於 `--jrpg-smoke`／`--jrpg-resume` 啟用。`--demo-profile` 使用獨立 Verification 存檔目錄，不改正式遊玩資料。

- 以真正 Input System 合成鍵盤事件，沿 BFS 路徑逐格走到商店、遠征入口及第一個敵人，轉向按 E；實際碰撞、介面鎖與鏡頭均由產品程式處理。
- 主選單、確認、第一個攻擊、畫廊與零 HP 安全返城使用 Input System 合成指標點擊。
- 後段多敵、Boss、H、記憶與魔化條件使用正式 Presenter／GameSession 命令，不直接填旗標。勝利後位置由正式地圖刷新處理。
- 重要分歧在真正條件成立後經確認，魔化技能正常勝利，再讀回分歧前；畫廊前後比較完整快照。
- 戰鬥動畫未結束時另開新旅程，等待超過動畫時間，確認新狀態未被舊回呼改寫。
- 真實敵方攻擊至 HP 0 後選續戰，H 勝利維持 0 HP，透過畫面安全返城按鈕返回。
- 第二個獨立 Player 程序按繼續，核對旅程、位置、回退計數與畫廊。

自動化會在驗證模式忽略焦點造成的裝置停用，並重新啟用測試輸入裝置；一般啟動不套用該設定。這些是自動程式內輸入，沒有宣稱人工完整鍵鼠操作。
